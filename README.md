# Pseudoscience (Minecraft 1.21.1 � NeoForge)

Pseudoscience is a mod themed around the scientific method, observation, experimentation, and hypothesis � but science left unchecked parallels madness.

**Pseudoscience**: beliefs or practices presented as scientific but lacking rigorous validation or reproducibility.

---

## Core Features
- **Materials & progression** grounded in material sciences, geology and chemistry.
- **Components with robust interaction**, designed to combine in unique ways across the tech tree.
- **Tools, gear, storage, and energy** built from advanced mesh systems.

---

## Core Material & Tech Tree (High Level)
- Raw Graphite ? Refined Graphite ? Graphene Mesh
- Devices & machines ? practical storage, energy, and utility
